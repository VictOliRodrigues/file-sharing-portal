# Screenshots

The `.svg` files here are placeholders so the README renders cleanly before a
deployment exists. Replace them with real captures of your own instance:

| File | What to capture |
| --- | --- |
| `dashboard.svg` | The signed-in dashboard, with a few files uploaded |
| `files.svg` | The file browser inside a folder, showing the breadcrumbs |
| `share-link.svg` | The share link detail page, or the public landing page |
| `admin.svg` | The administration dashboard |

PNG is fine too — update the image paths in the README to match.

Use a viewport around 1440 x 900, and make sure no real email addresses or file
names are visible.
